- [MFAAvalonia](#mfaavalonia)

## MFAAvalonia (v1.6.9)

### 启动

在GUI中，

1. 将“设置->启动设置->启动后操作”设为“启动软件并启动脚本”
2. 在“软件路径”中填入模拟器路径
3. 按需设置“等待软件启动时间”
4. （可选）将“结束后操作”设为“关闭MFA和软件”

MaaEOV即可在启动后自动启动模拟器，并开始按当前配置执行任务，并可以在任务完成后关闭模拟器和MaaEOV。

### 配置

MFAAvalonia支持通过启动命令，设置配置加载。

```
<MaaEOV根目录>/MFAAvalonia.exe -c <配置名>

# 加载config/示例.json
<MaaEOV根目录>/MFAAvalonia.exe -c 示例
```

### 定时

MFAAvalonia支持定时执行，但需要程序保持开启，推荐另行设置。

如使用Windows Task Scheduler设置计划任务。

1. 设置“启动后操作”并保存配置
2. 将要启动的程序或脚本设置为`<MaaEOV根目录>/MFAAvalonia.exe`
3. 添加参数`-c <配置名>`
4. 设置触发器定时

即可在指定时间启动MaaEOV和模拟器，并开始执行任务。

## MaaPiCli

### 启动

运行命令

```
<MaaEOV根目录>/MaaPiCli.exe -d
```

MaaPiCli会使用已保存的配置`<MaaEOV根目录>/config/maa_pi_config.json`直接运行。

MaaPiCli不会自动启动模拟器，需要另行设置。

### 配置

MaaPiCli的配置保存在`<MaaEOV根目录>/config/maa_pi_config.json`中，仅能通过该文件进行修改。

可以将配置好的文件复制出来重命名保存，如

```
copy <MaaEOV根目录>/config/maa_pi_config.json <MaaEOV根目录>/config/example.json 
```

需要时再覆写回去，即可实现切换配置。

```
copy /y <MaaEOV根目录>/config/example.json <MaaEOV根目录>/config/maa_pi_config.json
```

### 打包

可以用脚本打包切换配置、启动模拟器、等待模拟器、执行任务、关闭模拟器的流程。

```
REM run.bat

@echo off
setlocal

set "PRESET=%~1"

REM 设置MaaEOV根目录
set "MAAEOV_ROOT=<MaaEOV根目录>"

REM 加载配置
if not "%PRESET%"=="" copy /Y "%MAAEOV_ROOT%\config\%PRESET%.json" "%MAAEOV_ROOT%\config\maa_pi_config.json"

REM 启动模拟器
start "" "<模拟器路径>"

REM 等待模拟器启动
timeout /t 30 /nobreak >nul

REM 运行MaaPiCli
"%MAAEOV_ROOT%\MaaPiCli.exe" -d

REM 关闭模拟器
taskkill /F /IM "<模拟器进程>"

endlocal
```

即可运行`run.bat <配置名>`执行整套流程。

### 定时

MaaPiCli没有定时功能，需另行配置。

如使用Windows Task Scheduler设置计划任务。

1. 将配置好的`<MaaEOV根目录>/config/maa_pi_config.json`复制重命名，如`<MaaEOV根目录>/config/example.json`
2. 创建脚本，例如批处理文件`<MaaEOV根目录>/run.bat`
3. 将要启动的程序或脚本设置为`<MaaEOV根目录>/run.exe`
4. 添加参数`<配置名>`
5. 设置触发器定时

即可在指定时间启动MaaEOV和模拟器，并开始执行任务。

## 其他

无头服务器环境下，部分模拟器可能不稳定，安装虚拟显示器或使用显卡欺骗头可以改善。
