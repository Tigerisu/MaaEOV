## ⚠️ 使用须知

本项目已发布首个可用（大概）的 **Alpha 版本**，目前仅支持 **Windows 平台**。

请注意：

- 文档尚未完善，**仅推荐有其他 MAAFramework 项目使用经验的用户尝试**。
- 本版本仍处于早期阶段，**可能存在错误或不稳定情况**，建议在监督下使用。
- 由于《异象回声》桌面互通版需要跳转浏览器登录，**MaaEOV暂无对桌面互通版的支持计划**，请搭配模拟器使用。
