# MaaEOV

基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 的 [异象回声](https://eov.astral-vector.com/) 小助手。

## 功能列表

- 启动游戏
- 每周-阈限禁区
- 清体力
- 危机行动调令
- 事务所（解读仪式）
- 市区巡逻
- 领取任务奖励
- 领取应对协议
- 领取邮件
- 补给站
- 外部招募
- 退出游戏
- 活动-每日行动补给
- 联线封锁
- 活动-短期支援补贴

>[!NOTE]
>认知海域 的自动扫荡功能在更新计划中。
>鉴于官方直播中似乎提到过此玩法的优化计划，且该功能的实现较为复杂，故将其开发计划推迟到进一步稳定现有功能之后。
