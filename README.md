>[!IMPORTANT]
>
>请注意：
>
>- 当前版本整体已趋于稳定。建议首次使用时在监督下运行一次，以确认环境配置与功能运行是否正常。如在使用过程中遇到问题，欢迎通过 Issues 反馈。
>- 由于《异象回声》桌面互通版需要跳转浏览器登录，**MaaEOV暂无对桌面互通版的支持计划**，请搭配模拟器使用。
>
>本项目当前仍使用 **[MFAAvalonia](https://github.com/SweetSmellFox/MFAAvalonia)** v1.6.9。新版本 MFAAvalonia 近期已逐步趋于稳定，项目后续可能会升级至较新版本。若升级 GUI，用户可能需要额外安装 .NET 10，并对 配置文件 进行调整，具体说明将另行发布。

## 功能列表

- 启动游戏
- 每周-阈限禁区
- 清体力
- 危机行动调令
- 事务所（解读仪式）
- 市区巡逻
- 领取任务奖励
- 领取应对协议
- 领取邮件
- 补给站
- 外部招募
- 退出游戏
- 活动-每日行动补给
- 联线封锁
